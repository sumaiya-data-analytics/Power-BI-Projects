# Student Social Media Usage & Addiction Analysis

# Project Overview
This project focuses on analyzing social media usage and its impact on students' mental health, academic performance, sleep patterns, and relationships using Microsoft Power BI.

An interactive dashboard was developed to explore student behavior, identify patterns, and generate meaningful insights from the dataset.

# Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

# Project Objectives
- Analyze social media usage among students.
- Understand the relationship between social media addiction and mental health.
- Evaluate the impact of social media on academic performance.
- Analyze sleep patterns and relationship conflicts.
- Present insights through interactive dashboards.

# Key Features
- Interactive dashboards and visualizations.
- KPI cards and data-driven insights.
- Gender, country, academic level, and age-based analysis.
- Interactive slicers and filters.
- Drill-through functionality.
- Bookmarks for different report views.

# Dashboard Pages
1. Executive Overview
2. Mental Health & Lifestyle
3. Academic Impact
4. Relationships & Conflicts
5. Story View

# Key DAX Measures
- Average Sleep Hours
- Average Usage Hours
- Percentage of Students Affected Academically
- Addicted Student Count
- Total Students

# Key Analysis
- Addiction Score by Academic Level.
- Average Social Media Usage by Age.
- Gender Distribution.
- Mental Health and Sleep Analysis.
- Academic Performance Impact.
- Relationship Conflicts.

# Key Learnings
- Data cleaning and transformation using Power Query.
- Creating DAX measures.
- Designing interactive dashboards.
- Using slicers, bookmarks, and drill-through.
- Analyzing data and presenting meaningful insights.
